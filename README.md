# GreenClaim MVP

Чат-бот для мессенджера **MAX** на Python. Помогает гражданину оформить юридически грамотную
жалобу на экологическое нарушение: подбирает нормы права и ведомства-адресаты, подставляет
GPS-координаты и фото, выдаёт готовый PDF.

Соответствует плану из паспорта проекта: MVP для Калининградской области по двум сценариям —
**«незаконная свалка»** и **«вырубка»**.

## Как работает

```
/start → согласие на обработку данных → выбор сценария → 3 вопроса (тип земли, отходы/разрешение, масштаб/нарушитель)
       → фото (как файл, чтобы сохранился EXIF) → GPS из EXIF или геопозиция из MAX
       → описание → ФИО и адрес для ответа → сводка (нормы, адресаты) → PDF по 59-ФЗ
```

| Модуль | Назначение | Пункт паспорта |
|---|---|---|
| `data/legal_matrix.json` + `greenclaim/legal.py` | логическая матрица квалификации: ответы → теги → нормы КоАП/кодексов, адресаты, просительная часть | п. 12 «собственное решение» |
| `greenclaim/geo.py` | GPS и время из EXIF, проверка региона, ближайший муниципальный центр | п. 17, модуль геоданных |
| `greenclaim/routing.py` + `data/agencies.json` | подбор ведомств по типу нарушения и месту | п. 12, реестр зон ответственности |
| `greenclaim/pdf.py` + `fonts/` | PDF обращения (reportlab, ≈0,1–0,3 с), шрифт DejaVu Serif входит в проект | п. 17, цель ≤ 3 с |
| `greenclaim/storage.py`, `export.py` | обезличенные записи → GeoJSON (задел под B2B-карту рисков) | п. 9, 17 |
| `greenclaim/dialog.py` | диалоговый движок (состояния, кнопки, PDF), не зависит от мессенджера | п. 27 |
| `greenclaim/max_bot.py` | адаптер MAX (библиотека `maxapi`) | п. 27 |

## Запуск

### 1. Получить токен (главное организационное условие)
Бота в MAX может создать только **верифицированная организация** на платформе «MAX для партнёров»
(max.ru/business → профиль → Чат-боты): юрлицо или ИП — резиденты РФ, а с 15.06.2026 и самозанятые.
Нужны: профиль организации, верификация (через Госуслуги или банк), карточка бота и модерация.
Токен появляется в разделе **Интеграция → Получить токен**. Для проекта на базе вуза логичнее
всего регистрировать профиль БФУ (юрлицо) либо оформить бота на участника команды-самозанятого.
Актуальные правила: https://dev.max.ru/docs/chatbots/bots-coding/prepare

### 2. Установить и запустить
```bash
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                  # Windows: copy .env.example .env; вписать MAX_BOT_TOKEN
python -m greenclaim.max_bot                          # long polling
```
Для продакшна `maxapi` поддерживает webhook (`pip install maxapi[fastapi]`, `bot.subscribe_webhook(...)`,
нужен HTTPS-домен); для пилота хватит polling на любом VPS.

### 3. Шрифты для PDF
Шрифты DejaVu Serif лежат в папке `fonts/` (лицензия — `fonts/LICENSE-DejaVu.txt`), поэтому
PDF собирается на Windows, macOS и Linux без установки чего-либо в систему. Ничего настраивать
не нужно. Если вы переносите проект, не удаляйте папку `fonts/`; при желании другую папку
со шрифтами можно указать в `FONT_DIR`.

### 4. Особенности MAX, учтённые в коде
- Фото просим слать **как файл**: так в снимке сохраняется GPS. Если координат нет, бот показывает
  кнопку «📍 Отправить геопозицию» (`RequestGeoLocationButton`).
- PDF после загрузки в MAX обрабатывается не мгновенно: адаптер повторяет отправку при ошибке
  `attachment.not.ready`.
- Снимки HEIC с iPhone читаются при установленном `pillow-heif` (есть в requirements).

### 5. Проверить при первом запуске
Движок покрыт тестами, а адаптер написан по документации `maxapi` и проверен только на заглушке
библиотеки (доступа к реальному MAX при разработке не было). На живом боте пройдите сценарий
целиком и обратите внимание на:
1. определение `chat_id` события (`_sid` в `max_bot.py` пробует несколько полей);
2. что кнопка не «крутится» после нажатия: если да, добавить подтверждение callback (`event.answer(...)`);
3. что снимок «как файл» действительно приходит с GPS (EXIF), а как «фото» — возможно, нет;
4. что геопозиция из MAX приходит вложением `location` (`latitude`/`longitude`);
5. что PDF доходит и открывается на телефоне.

## Тесты и выгрузка
```bash
pytest -q                                      # матрица, EXIF, PDF, хранилище, сквозной диалог без сети
python -m greenclaim.export dump > dump.geojson   # обезличенная карта нарушений
```

## Что обязательно сделать до публичного запуска

1. **Юридическая верификация** (`data/legal_matrix.json`, `data/agencies.json`). Нормы подобраны
   как черновик; пункты с `confidence: "check"` (ст. 8.39 КоАП, Лесной кодекс без статьи, 131-ФЗ)
   и вся логика «городских насаждений» (там действует региональное законодательство и местные
   Правила благоустройства) нужно проверить юристам команды. Названия и контакты ведомств
   в `agencies.json` помечены `verified: false` и не содержат e-mail/адресов — их предстоит заполнить.
2. **Границы муниципалитетов.** Сейчас адресат-администрация определяется по ближайшему
   административному центру (приближение). Заменить на point-in-polygon по границам МО.
3. **Персональные данные.** ФИО и адрес живут только в памяти процесса на время диалога, в БД их нет;
   фото удаляются после генерации PDF. Формулировку согласия нужно утвердить юристом (152-ФЗ).

## Известные ограничения MVP

- Мессенджеры сжимают обычные фото и могут стереть EXIF — бот просит присылать снимок **как файл**,
  иначе запрашивает геопозицию отдельно.
- Диалог без LLM: детерминированная матрица (так проще проверять юристу и объяснять результат).
  «Вопрос-ответ» из презентации (свободный вопрос в чате) в этот MVP не входит — следующий шаг.
- Автоматической отправки жалоб нет: бот выдаёт PDF и инструкцию (Госуслуги / e-mail / почта).
- Сессии диалога хранятся в памяти процесса: при перезапуске бота незавершённые диалоги сбрасываются.

## Дорожная карта

1. Верификация матрицы и реестра ведомств → закрытое тестирование с эко-волонтёрами (гипотезы 1–3).
2. Новые сценарии: сбросы в воду, выбросы в воздух, незаконная добыча.
3. Свободный вопрос к боту (LLM поверх базы норм) — слайд 4 презентации.
4. Веб-карта и B2B-подписка (тепловая карта из `export_geojson`).
